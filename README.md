## Projetos em destaque

### [Validade Fácil](https://github.com/wellissonreis/validate-facil)

Aplicação mobile para controle de produtos, lotes e datas de validade em pequenos comércios. O projeto busca reduzir perdas por vencimento e simplificar a rotina de estoque por meio de leitura de código de barras, alertas e consultas rápidas.

**Tecnologias:** React Native, Expo e TypeScript.

### [Reis Inventory](https://github.com/wellissonreis/ReisInventory)

Plataforma de gestão de estoque com previsão de demanda, alertas de ruptura e sugestões de compra. A solução explora processamento em segundo plano, observabilidade e integração com modelos de linguagem executados localmente.

**Tecnologias:** .NET, ASP.NET Core, PostgreSQL, Redis, Docker, OpenTelemetry, Jaeger e Ollama.

### [GitHub Repositories API](https://github.com/wellissonreis/RepositoriosGitHubApi)

Aplicação para consumo e apresentação de dados de repositórios utilizando a API do GitHub, com foco em integração entre serviços e organização do código.
