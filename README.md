## Projetos

### [ReisInventory](https://github.com/wellissonreis/ReisInventory) — projeto principal

Backend para gestão de estoque, desenvolvido em .NET 10 e organizado em projetos de API, domínio, infraestrutura, Worker Service e testes.

A solução registra produtos e movimentações, calcula previsões a partir do histórico recente de consumo, estima risco de ruptura e gera sugestões de compra. Também possui integração com Ollama para recomendações em linguagem natural.

**Tecnologias:** ASP.NET Core, Entity Framework Core, PostgreSQL, Redis, Worker Service, Docker Compose, OpenTelemetry, Jaeger, Ollama e xUnit.

### [Validade Fácil](https://github.com/wellissonreis/validate-facil)

Produto mobile em desenvolvimento para apoiar pequenos comércios no controle de produtos, lotes, estoque e datas de validade. O aplicativo possui armazenamento local, leitura de código de barras, movimentações e indicadores de vencimento.

**Tecnologias:** React Native, Expo, TypeScript e AsyncStorage.

### [GitHub Repositories API](https://github.com/wellissonreis/RepositoriosGitHubApi)

Projeto complementar voltado ao consumo e à apresentação de dados da API do GitHub.
